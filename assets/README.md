# TwitchLite

Identidad: Glitch de Twitch en morado, con **lite** en minúsculas y verde neón `#39FF14` en la esquina inferior derecha. Fondo transparente; el distintivo lleva fondo oscuro para conservar el contraste en Windows.

El mismo PNG identifica la ventana, la interfaz y las notificaciones. El ICO incluye 16, 20, 24, 32, 40, 48, 64, 128 y 256 px y se integra como recurso del ejecutable.

Regeneración en Windows con Python y Pillow:

```powershell
python scripts/generate-branding.py
```

Referencia del Glitch: [Twitch Brand Assets](https://brand.twitch.tv/). La geometría también se comprobó con [Simple Icons](https://simpleicons.org/?q=twitch), consultado mediante Supericons. La marca Twitch pertenece a Twitch Interactive, Inc.
